# Corral

Группы для иконок на рабочем столе Windows.

Иконки раскладываются по областям прямо на рабочем столе. Сами файлы никуда не переносятся, они так и лежат в папке «Рабочий стол», Corral просто показывает их внутри группы.

## Как поставить

Скачайте `corral.exe` и `corral_agent.dll`, положите в одну папку и запустите `corral.exe`. В трее появится иконка, на рабочем столе пара групп для примера.

Чтобы он запускался вместе с Windows, откройте настройки (левый клик по иконке в трее) и поставьте галочку «Запускать при входе в Windows». Corral скопирует себя в `%LOCALAPPDATA%\Programs\Corral` и добавит задачу в Планировщик.

Если у вас стоит другая программа, которая раскладывает иконки на рабочем столе, закройте её перед запуском. Вдвоём они дерутся за иконки, и ничего хорошего из этого не выходит.

## Что можно делать

Группу двигаете за заголовок, размер меняете за правый или нижний край. Всё прилипает к сетке иконок, так что ровно получается само.

Иконки в группу можно просто перетащить. Или задать правило, например `*.pdf`, и все PDF будут попадать туда сами. Вытащить иконку обратно можно тоже перетаскиванием.

Если на группе нажать правой кнопкой по заголовку, там есть «Режим плашки»: группа сворачивается до одного заголовка и раскрывается, когда наводите мышь. Мне так удобнее всего, рабочий стол остаётся чистым.

Ещё есть порталы. Это группа, которая показывает содержимое какой-нибудь папки, например рабочей. Файлы в ней можно открывать, переименовывать и перетаскивать, как в Проводнике.

Остальное в настройках: темы (их там штук двадцать), цвета, прозрачность, скругление углов.

Конфиг лежит в `%APPDATA%\corral\config.toml`, это обычный текстовый файл. Его можно поправить руками, а потом выбрать в меню трея «Перечитать конфиг».

## Про `corral_agent.dll`

Чтобы иконка не показывалась два раза, в группе и на самом рабочем столе, оригинал нужно спрятать. Сам Проводник так не умеет, поэтому Corral загружает в него маленький модуль. Модуль ничего не патчит, он только не даёт Проводнику рисовать спрятанные иконки и нажимать на них. Когда Corral закрывается, модуль выгружается и всё возвращается как было.

## Когда работать не будет

- Вместе с другими программами, которые сами двигают иконки на рабочем столе.
- Размытия фона под группами нет и не будет, Windows его не даёт сделать для такого типа окон.
- Новое контекстное меню Windows 11 пока работает плохо, поэтому по умолчанию показывается старое. Включить новое можно в настройках, на свой страх и риск.
- Я пользуюсь Windows 11. На Windows 10 должно работать, но я не проверял.

## Собрать самому

Нужен Rust.

```
cargo build --release
```

Оба файла будут в `target\release`.
